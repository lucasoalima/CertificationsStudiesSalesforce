# Sharing and Visibility: access to other data (study notes)

## Reports and dashboards
Report results respect the running user's record access and field-level security. Dynamic dashboards run as the logged-in viewer, so each person sees only their data; a dashboard with a fixed running user shows everyone the data that user can see.

## Files and Salesforce Knowledge
Files shared to a record inherit access from the record. Knowledge articles use data categories and channels to control which users and audiences can see them.

## Experience Cloud (external users)
External users get access through external OWD, sharing sets (which grant access based on the user's account or contact, for high-volume licenses), share groups and sharing rules for roles-based licenses. Guest users have the most restricted access and records must be shared explicitly with them through guest user sharing rules.

## List views and search
List views and global search only return records the user can access through the sharing model, combined with object permissions and field-level security.
